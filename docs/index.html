Blip Notification

A small animated character at the top centre of your screen that tells you when Claude Code is done, needs you, or hit an error, so you can look away while it works.

What it tells you

WorkingClaude is busy.
Needs youA permission or a question is waiting.
DoneThe turn finished.
ErrorSomething went wrong.

Demo

Demo video coming soon.

Where it is today

  • The engine works on the Mac, tested live in the Claude Desktop app and the Terminal.
  • It listens on your own machine only, and never slows Claude Code down. If Blip is closed or frozen, Claude behaves as if it did not exist.
  • The character is being added to the window now. Windows and an installer come after.
