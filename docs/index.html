    You might be wondering

    Does it slow Claude down?

    No. I tested it with Blip frozen and with Blip quit. Claude carried on both times.

    Does it send my code anywhere?

    No. Everything stays on your computer.

    Does it work on Windows?

    Not yet. Blip is Mac only for now, and Windows is next on my list.

    Does it work with Cursor or Codex?

    With Claude Code, yes, wherever Claude Code runs. So far I've tested it in the Claude app and Terminal on a Mac. Codex and Cursor's own agent aren't supported yet.

    How do I install it?

    Ask Claude Code to do it. Paste this into Claude Code: Install Blip by following https://github.com/Mohamed-Shahzan/blip-notification/blob/main/INSTALL.md It explains each step and asks before running it. The first time takes about 15 minutes, mostly waiting for the build. The steps by hand are in the README. A one-click download comes later.
