What Sprout heard

    The states

    Click Sprout a few times and it'll tell you what's going on. Click it a lot and it gets fed up.

    How it works

    Claude Code can run a small command at each step of its work. Blip adds one that tells Sprout what just happened.

    1. Claude Codeasks for permission or finishes a task.
    2. A small commandsends one line to Blip. It gives up after 2 seconds, and Claude never waits for it.
    3. Blipgets it on your own computer. Nothing goes online.
    4. Sproutshows it at the top of your screen.

    Tested. I froze Blip on purpose, on a Mac and on Windows, and Claude didn't notice.

    Questions

    Does it slow Claude down?

    No. I tested it with Blip frozen and with Blip quit. Claude carried on both times.

    Does it send my code anywhere?

    No. Everything stays on your computer.

    Windows?

    It runs there, but Sprout isn't on Windows yet. Next on my list.

    Does it work with Cursor or Codex?

    With Claude Code, yes, wherever Claude Code runs. So far I've tested it in the Claude app and Terminal on a Mac. Codex and Cursor's own agent aren't supported yet.

    How do I install it?

    Right now you build it from the code. A proper installer comes later.
