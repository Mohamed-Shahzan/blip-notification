Questions

Does it slow Claude down?

No. Each hook gives up after 2 seconds and Claude never waits for it. I froze Blip on purpose and quit it, on a Mac and on Windows, and Claude carried on.

Does it send my code anywhere?

No. Blip only listens on your own computer. Nothing goes online.

Does it work on Windows?

Yes. The same install line works there. Tested in the Claude app and in Antigravity.

Where does it work?

Anywhere Claude Code runs on your own computer. Not on claude.ai in a browser, because that runs in the cloud. Codex and Cursor's own agent aren't supported.

How long does installing take?

About 15 minutes the first time on a Mac, mostly waiting for the build. Claude does the work and asks before each step.

What does it cost?

Nothing. No account, no sign-up. Free to use, including at work.
